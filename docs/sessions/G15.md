# G15: Bản exe demo để gửi bạn bè (7/11/2026), kế hoạch

Viết cho: người dùng và agent mở phiên sau. Chen ngang đợt "rà lỗi tiềm ẩn / độ ổn định" (đợt đó đã hỏi xong hai vòng, chưa sửa file nào; câu trả lời chép ở cuối để làm tiếp).

## Bản chốt hỏi đáp
- Làm exe NGAY, đợt sửa độ ổn định làm SAU.
- Dạng gửi: thư mục nén .zip, bạn bè giải nén rồi bấm đúp exe (không dùng một file exe duy nhất: chậm mở, hay bị Defender nghi).
- Giấy phép: người dùng tự xác minh nguồn các file "CHƯA RÕ" trong `CREDITS.txt` (model Glock, tiếng súng M4, tiếng nền hồ bơi, gói âm thanh có điều kiện) rồi báo agent. Zip chỉ nằm trên máy; người dùng tự gửi sau khi xác minh.

## Mục tiêu đo được
1. `tools\build\build_exe.py` dựng được `build\FPS_prototype\FPS_prototype.exe` + `build\FPS_prototype_demo_<ngày>.zip`, in cỡ zip.
2. Bản dựng chép sang thư mục KHÁC có dấu cách, chạy với PATH không có `.venv` / Python: `--window --quit-after 10` thoát mã 0, ghi `logs\crash.log` cạnh exe, KHÔNG nướng lại ánh sáng (bộ đệm nướng đóng gói khớp thông số mặc định; script kiểm khoá trước khi đóng gói).
3. Bản console (`--console`) chạy như trên không in lỗi nạp model / âm thanh / shader.
4. pytest không đổi (không sửa mã game).

## Làm / KHÔNG làm
- Làm: PyInstaller 6 dạng thư mục, mọi file cạnh exe (`contents_directory='.'`, nên `ROOT` của `fps/app.py` đúng như khi chạy nguồn); chỉ chép tài nguyên game dùng; `HUONG_DAN.txt` (phím, yêu cầu máy, gặp lỗi gửi gì); `requirements-build.txt`.
- KHÔNG: ký số exe, cài đặt (installer), tự cập nhật, bản cho Linux / macOS, sửa lỗi độ ổn định (đợt sau).

## Kết quả (7/11/2026)
- Mục tiêu 1: dựng ~90 s; thư mục 192 MB, zip 88 MB (`build\FPS_prototype_demo_20261107.zip`).
- Mục tiêu 2: bản giải nén từ zip vào thư mục có dấu cách ngoài dự án, PATH chỉ còn `C:\Windows\System32;C:\Windows`, thư mục làm việc khác thư mục exe: `--window --quit-after 10` thoát 0; không tham số (phủ kín màn hình) `--quit-after 8` thoát 0; `logs\crash.log` cạnh exe; `lightmap.png` không đổi (không nướng lại); không sinh `user_*.json`.
- Mục tiêu 3: bản `--console` không in lỗi nạp model / âm thanh / shader (chỉ cảnh báo thường của Panda); ảnh chụp lúc chạy thấy phòng hồ, nước, nắng, súng đang rút.
- Mục tiêu 4: pytest 666 qua (bỏ 2 file nợ cũ như trước).
- Lòi thêm: lần dựng đầu chết ở `gltf_patch` (`inspect.getsource` cần mã nguồn thư viện gltf): script chép kèm các file .py của gói `gltf`. Dòng `build/` trong .gitignore khớp cả `tools/build/`: đổi thành `/build/`.
- Chưa kiểm: card NVIDIA / AMD, Windows 10, máy không có sẵn VC++ runtime (PyInstaller đã chép các DLL Python cần). Giấy phép: chờ người dùng xác minh.
- Đã tái dùng: `bake_key` / `reflect_key` (kiểm bộ đệm nướng), `GUNS[*].glb` (danh sách model), `tools\with_game_lock.py`.

## Đợt độ ổn định (làm sau), câu trả lời đã chốt
- Chuẩn: Microsoft XR-001 / XR-003 (không crash, không treo, không chết im lặng, tuỳ chọn giữ sau khi mở lại, không kẹt người chơi) + checklist phát hành indie (khởi động ≥ 99%, 0 lỗi P0/P1, file lưu hỏng không làm chết game, chơi lâu không phình bộ nhớ). Bỏ phần Xbox Live / thành tích / mạng / Steam Deck.
- Lỗi Python lạ giữa lúc chơi: hộp thoại + ghi log, rồi thoát.
- Alt+Tab / thu nhỏ: nhả chuột, nhả phím, tắt tiếng; quay lại không giật camera.
- File nướng hỏng: tự nướng lại (ghi file kiểu an toàn: file tạm rồi đổi tên).
- Thoát game: giữ nguyên (Alt+F4).
- Kiểm: công cụ phá game thật (bấm phím ngẫu nhiên, file hỏng, khựng 2 s), bản ngắn ~1 phút làm cổng + bản dài 10 phút đo bộ nhớ.
- Commit: mỗi chỗ sửa một commit, liền một mạch.
- Đã thấy khi rà (chưa sửa): `user_graphics.json` dạng lạ (mảng, `graphics` không phải object) làm chết lúc mở (`from_json` chỉ bắt OSError / ValueError); `lightmap.png` / `reflect.png` / `ambient.json` hỏng làm chết lúc mở; `save_graphics` ghi thẳng (không file tạm); lỗi Python giữa trận không vào `logs/crash.log`; không xử lý mất tiêu điểm cửa sổ; `--size` sai dạng làm chết; `desktop_size()` không có dự phòng.
